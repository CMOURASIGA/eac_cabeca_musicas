# Pasta de TXT de origem (carga real das 41 músicas)

Coloque aqui os arquivos `.txt` reais das músicas (extraídos do PDF
`Meu Canto, Minha Fé - Banda EAC Porciúncula`, ou já preparados por vocês).
Pode subir um por um ou todos de uma vez pelo GitHub web
(**Add file → Upload files**, dentro desta pasta).

Não precisa se preocupar com formatação perfeita — o parser aceita tanto
TXT com front matter quanto o formato legado simples:

```txt
---
title: SOMOS LUZ
collection: EAC
key: A
number: 41
---

[Verso 1]
A
Caminhando lado a lado
```

Sem front matter também funciona (título/tom não detectados
automaticamente ficam marcados para revisão manual na importação).

Esta pasta é só uma área de trouxa/staging: depois que os arquivos
estiverem aqui, eu sigo o processo real de importação
(`docs/CHECKPOINT_BASE_TXT_IMPORT_READY.md`) — nada é publicado
automaticamente só por estar aqui.
