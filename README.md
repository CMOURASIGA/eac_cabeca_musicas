# Livro de Músicas EAC

Base de especificação e arquivos TXT iniciais para o WebApp público de músicas do EAC.

## Conteúdo inicial

Após executar `python3 tools/extract_song_txt.py`, os 41 TXT de origem ficam em `content/songs-source/`, com `manifest.csv` para conferência e importação. Eles reproduzem o material enviado como base e devem passar por revisão editorial antes da publicação no aplicativo.
